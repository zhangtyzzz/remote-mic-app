# Agent Controller 本机与遥控器测试手册

## 适用范围

- 功能分支：`codex/agent-controller-platform`
- 测试包：SayAll `1.9.7 (130)` Apple Silicon 本机 ad-hoc 构建
- 支持目标：Codex、Claude Code、Grok Build、Antigravity、OpenCode
- 功能边界：桌面目标负责打开并聚焦安全输入区；终端目标只聚焦 cmux 中已经启动的当前会话，不自动执行 CLI、不新建会话，也不绕过 Agent 自身确认。
- 本手册不把自动化、截图或 ad-hoc 构建等同于真实小米蓝牙遥控器 2 Pro 验收。

## 测试前准备

1. 退出其他 SayAll / Remote Mic 版本，安装并启动本次测试包。
2. 在“系统设置 → 隐私与安全性”中给本次 App 开启蓝牙、输入监控和辅助功能权限；若覆盖 App 后权限失效，先重新授权。
3. 在系统蓝牙设置中连接小米蓝牙遥控器 2 Pro，并完成 SayAll 首次设置。
4. 桌面目标至少安装一个：Codex、Antigravity、OpenCode。
5. 终端目标需要安装 cmux 及对应 CLI；测试前先在当前 cmux 会话中人工启动 `claude`、`grok`、`codex`、`agy` 或 `opencode`。

## 用例 1：安装发现与选择

1. 打开“Agent 控制”页面。
2. 检查五张目标卡片的安装状态和控制路径。
3. 逐个点击“设为当前”，然后点击“打开并聚焦”。

预期结果：

- Codex、Antigravity、OpenCode 优先使用已安装桌面 App。
- Claude Desktop 不能被误识别为 Claude Code；只有检测到 `claude` CLI 才启用 Claude Code。
- 只有 CLI、没有 cmux 时显示缺少终端宿主并保持不可控制。
- 选择会跨 SayAll 重启保存。

## 用例 2：推荐遥控器映射

在“按键”页面为当前遥控器建立一套测试映射：

- 左键：切换到上一个 Agent。
- 右键：切换到下一个 Agent。
- 主页键：打开当前 Agent。
- OK：发送给当前 Agent。
- 返回键：中断当前 Agent。

为了不覆盖日常映射，也可以先把这些动作放到双击或长按。保存后回到“Agent 控制”页面观察当前目标，再使用实体遥控器触发。

预期结果：

- 上一个 / 下一个只在当前可控制目标间循环，并在切换后打开和聚焦新目标。
- OK 只在所选桌面 App 或 cmux 确实位于最前台时发送 Return。
- 返回键只在所选目标位于最前台时发送：桌面端为 Escape，终端端为 Control-C。
- 如果前台不是所选目标，发送和中断都应安全拒绝，不把按键发给其他 App。

## 用例 3：五个目标逐项验证

对本机可用的每个目标分别检查：

- [ ] 未运行时可打开，或终端会话已由用户人工启动。
- [ ] 位于后台时可切到前台并聚焦输入区。
- [ ] 已在前台但焦点位于侧栏或工具栏时，可重新聚焦输入区。
- [ ] 输入一段无副作用的测试文字后，OK 只提交一次。
- [ ] 运行一个可安全取消的任务后，返回键只中断一次。
- [ ] 切到其他 App 后按 OK / 返回键，不会向错误窗口发送按键。
- [ ] SayAll 重启后仍保留上次选择。

## 用例 4：真实遥控器与回归

- [ ] 小米蓝牙遥控器 2 Pro 的单击、双击、长按没有串动作或连发。
- [ ] 遥控器断连再连接后，Agent 动作恢复且目标选择不丢失。
- [ ] 语音键、普通方向键、音量键和既有 App 动作没有回归。
- [ ] 中文 / English、浅色 / 深色以及 `1020 × 772` 页面无裁切；`800 × 650` 下可滚动访问全部目标和动作说明。

失败时保留目标 App、是否前台、触发按键和实际结果；运行日志位于 `~/Library/Logs/RemoteMic/runtime.log`。不要在日志或 Issue 中粘贴 Agent 对话、Token、密钥或其他敏感内容。
